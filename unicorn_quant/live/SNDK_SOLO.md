# SNDK单票方案（代号 sndk_solo）

宝贝自己的 C 账户只跑这一个方案，和方案F、趋势A、chan_resid、擂台等以前的方案完全分开。
聊天里说"SNDK单票"/"单票方案"就是指它。

## 命名规则

`SNDK单票方案 <版本>·<模式>·<账户>`，例如 **SNDK单票方案 v3·C账户**（当前实盘，默认模式可省略）。

- **版本号**：交易规则（进出场、止损、周期、方向）变了才升，v1 → v2 …；每次升版本先回测，写进 research.json，再改 `VERSION`。
- **模式**：同一版本规则下的仓位方式，用开关文件切换，不升版本号。
- **账户**：目前只有 C（binanceC）。

## 模式（开关文件都在 VPS `/home/binanceC/sndk_solo/`）

| 文件 | 作用 |
|---|---|
| （默认） | 仓位 = 开仓时净值 × ADX 档位倍数（1 / 0.75 / 0.5），不满一手往上取到下一手 |
| `VOLSIZE` | **再叠加波动调仓**：倍数再取 min(·, 2% ÷ 1h ATR%)，财报等剧烈波动时进一步减仓 |
| `ARMED` | 有它才真实下单（没有 = 影子模式，只算不下单） |
| `STOP` | 一律不下单（紧急停） |
| `JOIN` | 立即跟上回测当前已有的持仓（默认只跟 ARMED 之后的新开仓信号） |

交易所设置：SNDKUSDT 全仓、杠杆 75x（只为少占保证金，实际仓位仍≈1倍）、双向持仓模式（执行器带 positionSide=LONG）。

## 执行

- 下单：只做 Maker 的限价单（GTX，挂单费 0），每分钟按最优价重挂，15 分钟没成交完用市价补。
- 信号：每轮从 SNDKUSDT 上线（2026-04-07）起把全部 1h K线按回测逻辑重放一遍，实盘 = 回测本身。
- 自己的订单 clientOrderId 前缀 `ss_`；账户里别的持仓不碰，只钉钉告警。
- 钉钉：看门狗机器人，消息开头【SNDK单票方案 v3·C账户】。

### 实盘怎么复刻回测（2026-10-31 补齐）

| 回测里 | 实盘里 |
|---|---|
| 1h K线收盘判断 | 每 30 秒用币安 SNDKUSDT 1h K线从上线起重放一遍；K线收盘 10 秒后才用（确保是定稿数据），信号最晚约 40 秒内发现 |
| 下一根开盘成交 | 发现信号立刻挂只做 Maker 限价，每分钟按最优价重挂，15 分钟没成交完用市价补 |
| 开仓价 − 4×ATR 止损，K线最低价碰到就出 | 开仓时就挂交易所 STOP_MARKET（按最新成交价触发，已实测可挂可撤）；另有**软件止损兜底**：最新价已在止损价下方(跳空/止损单没挂上)就立刻平 |
| 止损后等转空再进 | 交易所止损触发后锁定，等回测转空才解锁 |
| 周末不判断 | 同（纽约时间周六日） |
| 仓位按 ADX 档位 | 同，不满一手往上取一手（这一点和回测略有不同：43.8U 时满档约 1.06 倍） |

**对账和监控**
- `trades.jsonl`：每笔实盘成交记录均价、回测参考价（信号后那根 K线开盘价）、偏差 bp、手续费、挂单成交笔数、用时；成交时钉钉报一次。
- 日报（UTC 00:35）：净值、持仓、信号状态、**ARMED 以来 实盘净值% vs 回测%**。
- **专属监督狗 `sndk-solo-watchdog`**（常驻，每 60 秒，root 运行；替代原来只报警的体检）。原则：执行器活着时只盯不抢活，执行器"该做没做"或挂了才出手，动作只限保护性的，**从不开仓**：

  | 发现 | 自动处理 |
  |---|---|
  | 执行器服务停了 / 状态 3 分钟没更新(卡死) | 重启服务（1 小时最多 3 次，超过只报警） |
  | 有多单但交易所止损单没覆盖全部数量 | 执行器活着先等 2 轮，还没补就监督狗按回测止损价补挂；执行器挂了立即补 |
  | 最新价已在止损价下方（止损单没触发/跳空） | 立即市价平（执行器正在平就不重复下单） |
  | 执行器挂了 3 分钟以上、回测已经是空仓 | 按回测规则市价平 |
  | 空仓却挂着 ss_ 止损单/限价单，执行器也没有进行中的单 | 撤掉孤儿单 |
  | 方案以外的持仓/条件单 | 只报警，不动 |
  | 执行器 10 分钟报错≥5 次 / 净值一天内从高点跌超 15% / 日志超 20MB | 报警 / 轮转日志 |

  每天 UTC 00:40 发监督狗日报（检查轮数、自动处理了什么）。执行器反过来盯监督狗：`watchdog.json` 超过 10 分钟没更新就报警。
  2026-10-31 演练：停掉执行器 → 40 秒内被拉起；冻结执行器进程 → 约 2 分钟判定卡死并重启；持仓相关 9 种情况用模拟交易所逐一验证，动作全部正确。

**和回测仍有的差别（无法完全消除）**：成交价是挂单价而不是整点开盘价；手续费按真实的挂单 0 / 吃单 0.04%（回测按 0.08% 算，实盘应略好）；仓位往上取整；资金费（回测未计，约每半年 2% 净值）。

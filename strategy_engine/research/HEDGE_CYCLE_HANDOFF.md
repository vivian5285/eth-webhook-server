# EMA 趋势对冲循环：Claude / Codex 维护入口

2026-10-05。已授权范围是擂台纸面模拟，使用 Gate 公开数据。没有真实下单、交易所持仓模式设置、账户杠杆修改或凭证读取。原 ADX 双引擎和其他策略继续使用原引擎；本实验独立运行。

## 先读结论

同一个线性 USDT 永续合约，多空同时持有并不创造额外价格收益：价格变动损益 = (多数量−空数量)×价格变化。多空重叠部分主要增加手续费、保证金和换手；相同费率下，其资金费率也按净数量抵消。部分兑现顺势盈利不是账户整体盈利，旧对冲的亏损必须一起计入权益。

因此同时上擂台两组：

| 名称 | 作用 |
|---|---|
| `ema_hedge_cycle_4h_1d` | 双腿趋势对冲循环实验 |
| `ema_hedge_net_control_4h_1d` | 镜像实验组每个品种的多减空数量，只持净方向 |

每组独立初始 $1000。每组内部 ETHUSDT、SNDKUSDT、XAUUSDT 三品种共用同一份现金、权益、回撤和风险限额。对照组是净敞口成本诊断，不是独立产生信号的完整趋势策略；若自身限额/熔断导致无法镜像，记录 `net_control_tracking_clamped`，报告跟踪误差，不能再当作精确同敞口比较。

## 相对 DeepSeek 草案的明确改动

1. 日线方向和 EMA7 三根斜率要求同时同向，去掉“方向或斜率”的 OR；4h 连续两根确认。反转检查当前双周期排序与斜率，不要求二者恰好同时交叉。
2. 逆势仓不累计、不摊平。循环时平掉全部旧对冲，建立递减的新对冲；每笔逆势仓固定 1ATR 止损，主仓 2ATR 跟踪只收紧。对冲被止损后允许暂时单向，直到下一次有效入场/循环；不为了“永远双持”反复刷手续费。
3. 循环先要求两腿组合扣剩余入场费、已发生资金费用后的浮盈大于保守的成本门槛，并且主仓浮盈。不能只看多单盈利。代码门槛 = 主仓当前名义×2×(费率+滑点)×2。
4. 每轮平主仓 25%；再入场名义最多为初始主仓名义×[1,0.5,0.25]，且受“释放名义 + 正已实现利润×模拟合约杠杆×50%”限制，仍需通过所有账户限额。这是递减上限，不是保证每轮都增加主仓数量；成本、波动和风险可能使主仓净数量下降。最多三轮，之后管理仓位到止损/反转。
5. 对冲初始/第一轮目标主仓 30%，以后约 20%、15%；硬上限始终 50%。主仓减少时同步缩减对冲，主仓止损时连同对冲退出，不平盈利侧却留下失去逻辑的亏损侧。
6. 震荡、双周期矛盾或死水只减半一次，停止新增；不每分钟反复减半。趋势恢复不自动补回亏损仓，只接受下一根新闭合 4h 的有效决策。
7. 反转先退出旧主仓，不按盈亏决定保留。旧对冲若仍存在，改为新主仓，再按预算补充新方向和小额保护仓。没有合法主仓时，不保留孤立对冲。
8. 风控优先于底仓和双持承诺；价格变化造成超限也会比例减仓。15% 盯市回撤或权益逼近保守维持保证金需求时清仓、持久停机，无自动重置本金/复活。
9. 排名看两腿盯市权益并预留全部退出手续费与滑点。普通策略仍按原已实现收益排序，侧栏文字明确两种口径；不同口径的混合名次不宜用于严格策略优劣结论，应重点比较这两组同时开始的实验。

## 数据、信号和成交时序

- Gate ETH_USDT、SNDK_USDT、XAU_USDT 公开交易 4h/1d K 线作为信号；仅闭合 K 线，日线不提前读取。
- EMA7、EMA25、斜率回看3；均线距离/ATR<0.3，或 ATR14 低于前100个 ATR 的30%分位，或周期/斜率矛盾，停止新增。入场不额外要求 ADX；这是与已有 ADX 实验独立的用户 EMA 方案。
- 首次入场/反转/循环每根新闭合4h最多决定一次。循环需距离上次锚点≥1ATR，且收盘突破前20根高/低，或 ATR 扩张且实体>前20根均值1.25倍。
- 初始单品种主仓名义不超过账户权益50%，同时按初始止损风险0.5%反算；并非 ETH/SNDK/XAU 各自拥有3倍独立预算。
- 60秒轮询 Gate 当前 mark，按实际决策时刻 mark 加不利滑点模拟成交，不用几个小时前的信号收盘价成交。先检验旧止损，再收紧主仓跟踪止损；不把整根历史高低价格回溯当作已经发生的实时成交。
- 4h信号过期超过额外4小时、日线过期超过2日、历史不足、价格无效，则不开新仓。高周期信号缺失时仍在有完整当前 mark 的情况下处理已有止损。
- 三个当前 mark、资金费用历史、合约元数据任一缺失/无效则本轮不提交，两组账本都不部分更新。行情故障时无法保证止损执行，网页超过180秒无成功轮询显示 stale_data，journal记录错误。
- 全部新策略只使用 Gate。原 OPENAIUSDT/ANTHROPICUSDT 存量策略的币安例外按用户决定保留，不能扩散到新实验。

## 账户硬约束

| 项目 | 上限/假设 |
|---|---|
| 多名义 + 空名义（不能相互抵消） | 权益×3 |
| 模拟合约杠杆 | 固定10倍，用于保证金计算；没有改变真实账户 |
| 总保证金 | 权益30% |
| 任一方向保证金 | 权益20% |
| 单笔新增到止损风险 | 权益0.5%，包含不利止损滑点与退出费 |
| 所有腿从当前权益到止损风险之和 | 权益2.5%，不依赖跨品种/多空抵消 |
| 对冲数量 | 当前同品种主仓数量50%以内 |
| 账户最大回撤 | 峰值盯市权益下跌15%清仓停机 |

“总敞口3倍”和“保证金30%”只有指定合约杠杆才能一起解释：3/10=30%。保证金按多空毛名义分别计算，不使用交易所可能给予的双仓保证金抵扣。Gate 合约最大杠杆启动时校验≥10，维持保证金率取当前公开元数据。这是保守简化模型，不模拟交易所完整风险档位/强平系统。限额会二分缩小新增量，碎单名义<$1不成交。价格跳空、行情断联、资金费用或退出成本仍可能使实际亏损超过止损预算；预算不是损失担保。

## 成本与会计：修改前必须理解

普通 taker 固定0.075%，每个开/平仓都收费；每次成交不利滑点2bps。滑点进入成交价，不再额外扣一次现金。数量用标的单位的连续数，未模拟合约整数手数、最小委托量和真实成交深度。

实时资金费用拉取 Gate 已结算 `funding_rate` 历史事件，以事件时间去重持久化，不硬编码8小时。当前元数据 ETH/SNDK 为8小时，XAU为4小时，未来以返回事件和元数据为准。结算标记价用事件之前最后闭合 `mark_` 1m收盘近似，非交易所账户的官方账单价；部分事件整点晚几秒，须按分钟向下对齐，不能直接以“事件秒−60”匹配K线。正费率多付空收，仅收费给事件之前已存在的腿。首次创建账户前的历史事件不会收费。

核心恒等式：`cash = 1000 + realized_gross - fees + funding`；`equity = cash + 多空浮盈亏`。OPEN立即扣入场费；CLOSE只再扣退出费，分摊的入场费只用于交易报表，不能重复扣现金；已支付/收到的 funding 按部分平仓数量比例分配到平仓净损益，现金不得再次加减。完全清仓后，全部平仓净损益之和应等于cash−1000。

事件时间为实际决策时间，资金费用为实际历史事件时间。资金费用先补齐，再进行本轮成交；账户状态、两组事件、快照在一笔 SQLite 事务提交；失败回滚两组。保存cycle、last_bar、funding_cursor、事件序号、峰值权益、paused，重启不得重复开仓/收费。单进程flock阻止重复服务。

网页“平仓成交”包含部分止盈，胜率是成交片段胜率，不能等同完整趋势轮次胜率。“最差单笔”同样是成交片段。品种页现金贡献包含入场费和资金费用；不是尚未平仓浮盈，也不是分给该品种的独立账户净值。

更改参数不能偷偷重置已有权益；runner发现配置与已保存config不同会拒绝继续。更改策略需明确迁移持仓和历史，或另建实验名称/数据库同时比较。paused不得直接SQL改回false；先审查熔断原因，再明确建立新实验或人工授权恢复方案。

暂停新实验：`systemctl stop strategy-hedge-cycle.service`。保留库和代码以便恢复；不删除原擂台数据。回滚网页使用部署前备份，重启 `roster-dashboard.service`。原strategy-roster、实盘服务不需要重启。

历史回放计入手续费、滑点、实际历史资金费率，但只在4h收盘检查止损，结算mark用此前闭合mark_4h收盘近似，固定当前元数据且无整数手数/盘中路径。这不是精确回测，更不能凭结果承诺收益。对冲和对照应主要比较同步运行后的净收益、最大回撤、费用、换手、净敞口跟踪误差，以及各品种拖累。先检验对冲的价值，再考虑增加ADX分层或其他参数；首轮不做按历史利润挑选参数。
